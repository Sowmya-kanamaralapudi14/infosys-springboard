
AI-PriceOptima
Dynamic Pricing Recommendation System
====================================

1. Introduction
---------------
AI-PriceOptima is an end-to-end Dynamic Pricing Recommendation System designed to help businesses make smarter pricing decisions using data and machine learning. Pricing plays a crucial role in revenue, profitability, and inventory movement. Traditional static pricing or rule-based approaches often fail to adapt to changing demand, competition, and inventory levels.

This project demonstrates how Artificial Intelligence and Machine Learning can be applied to real-world retail pricing problems. The system provides real-time, business-friendly price recommendations using only four simple user inputs while the backend handles all complex processing automatically.

The goal of AI-PriceOptima is not just to predict prices, but to recommend optimal prices that balance demand, competition, and inventory, ultimately improving revenue and operational efficiency.


2. Project Objective
-------------------
The main objective of this project is to build a practical, easy-to-use AI-based pricing system that can:

- Recommend optimal product prices in real time
- Improve revenue and profit margins
- React to demand and competitor pricing
- Reduce excess inventory or stockouts
- Hide technical complexity from business users

Business users only need to enter:
- Cost
- Demand
- Inventory
- Competitor Price

All other features are automatically generated by the backend, making the system simple, fast, and scalable.


3. Dataset Description
---------------------
The datasets used in this project are stored in the `dataSet/` directory. Example files include:
- revenue_lift_9pct_30000.csv
- master_dataset_cleaned.csv

The datasets represent typical retail transaction data and include the following information:
- Date and time of sales
- Product ID and category
- Selling price and cost price
- Units sold
- Inventory or stock level
- Competitor pricing
- Revenue and derived KPIs

These datasets contain real-world noise such as:
- Missing values
- Outliers
- Irregular demand patterns

Such imperfections are intentionally handled during preprocessing to reflect real production scenarios.


4. Data Preprocessing and Feature Engineering
---------------------------------------------
Before training any model, extensive data preprocessing and feature engineering were performed.

Key steps include:
- Handling missing values
- Removing or capping extreme outliers
- Converting date columns into usable formats

Feature engineering plays a major role in model performance. Important engineered features include:
- Temporal features: day, month, weekday, weekend
- Lag features: previous day/week sales
- Rolling statistics: moving averages and trends
- Inventory ratios: stock vs demand
- Competitor deltas: difference between own price and competitor price
- Interaction features combining demand, inventory, and price

All these features are generated automatically in the backend during prediction.


5. Model Development
--------------------
Multiple pricing strategies were evaluated during model development.

First, a rule-based pricing baseline was implemented to serve as a reference. This approach adjusts prices based on simple heuristics such as demand and inventory thresholds.

Next, machine learning models were trained and evaluated:
- Tree-based regression models
- XGBoost and LightGBM (optional)
- Time-based train-test splits to avoid data leakage

Models were evaluated using simulated pricing scenarios and KPI improvements. The best-performing model can be saved as `pricing_model.joblib` for production use.

A fallback model is included in the backend to ensure the API remains functional even if the trained model file is not available.


6. Key Performance Indicators (KPIs)
------------------------------------
The following KPIs were used to evaluate pricing performance:

- Revenue Lift
- Profit Margin Improvement
- Conversion Rate
- Inventory Turnover

From notebook simulations and backtests, the system achieved:
- Revenue lift of approximately 10–11%
- Profit margin improvement of around 4%
- Inventory turnover improvement of about 7–8%

These results demonstrate the effectiveness of AI-driven pricing compared to static pricing strategies.


7. Backend Implementation (FastAPI)
----------------------------------
The backend of AI-PriceOptima is implemented using FastAPI.

Main features:
- Fast and lightweight REST API
- Input validation using Pydantic
- CORS enabled for frontend communication

Key endpoints:
- GET /
  Health check endpoint

- POST /predict_price
  Accepts cost, demand, inventory, and competitor price
  Returns a recommended price in JSON format

The backend loads a trained ML model if available. Otherwise, it automatically switches to a fallback pricing logic to ensure uninterrupted functionality.


8. Frontend Dashboard
---------------------
The frontend is built using React with Vite for fast development and performance.

Dashboard features:
- Clean two-column layout
- Input panel for user values
- Output panel for recommended price
- Clear call-to-action buttons

Users can:
- Enter four input values
- Click “Predict Price”
- Instantly view the recommended price
- Reset inputs easily

The UI is designed for non-technical business users, focusing on clarity and usability.


9. Deployment and Execution
--------------------------
To run the project locally:

Backend:
- Navigate to project root
- Run: uvicorn main:app --reload

Frontend:
- Navigate to frontend directory
- Run: npm install
- Run: npm run dev

The application can be accessed via the Vite development URL, typically http://localhost:5173.
